# Duke Fleet: голосовой мод для «Мира кораблей»

Оригинальный персонаж: самоуверенный герой боевика 90-х с низким хриплым баритоном. Это пародийная ассоциация, а не клон конкретного актёра. В версии v1 62 реплики на 30 боевых событий, у частых событий по 3–4 варианта.

## Что лежит в папке

| Путь | Что это |
|---|---|
| `script/lines.csv` | Сценарий, единственный источник правды: id/имя файла, событие, RU/EN текст, эмоция, темп, указание |
| `voice/character_brief.md` | Профиль голоса, промпт для Voice Design, тестовая тройка реплик для кастинга |
| `tools/make_tts_package.py` | Собирает пакеты для TTS (ElevenLabs v2/v3, простой текст) и сценарий для живого актёра |
| `tools/tts_generate.py` | Генерирует WAV через ElevenLabs API (по желанию, можно озвучивать любым другим способом) |
| `tools/postprocess.py` | ffmpeg: обрезает тишину, компрессирует, нормализует до −16 LUFS, пишет 48 кГц моно 16 бит; `--radio` добавляет эффект корабельной связи |
| `tools/build_mapping.py` | Проверяет комплект, длительность реплик и собирает таблицу соответствия для SoundModCreator |

Нужны Python 3.9+ без сторонних пакетов, а для `postprocess.py` ещё и `ffmpeg` в PATH.

## Разметка сценария

- `//` в тексте означает драматическую паузу. Для ElevenLabs v2 она превращается в `<break time="…"/>`, в остальных случаях в `...`.
- `frequency` (high / medium / low) показывает, как часто срабатывает событие. От него зависит лимит длины: high до 2,5 с, medium до 3,5 с, low до 5 с.
- `trigger_check = проверить`: у события может не оказаться отдельного голосового триггера в игре (например, «ГК — огонь», «уклонились», «мало HP», «ремонт»). Если в SoundModCreator такого события нет, реплики остаются в запасе.
- `origin = v1+` помечает добавленные варианты для частых событий, чтобы одна и та же фраза не повторялась каждые 20 секунд. Лишние можно просто удалить из CSV.

## Пайплайн

```bash
cd duke_fleet

# 1. Пакеты для TTS и сценарий для актёра -> build/tts/{ru,en}/
python3 tools/make_tts_package.py

# 2a. Генерация через ElevenLabs (сначала кастинг на тестовой тройке)
export ELEVENLABS_API_KEY=...  ELEVENLABS_VOICE_ID=...
python3 tools/tts_generate.py --lang ru --only DF_battle_start_01,DF_torps_detected_01,DF_ship_destroyed_04 --takes 3
python3 tools/tts_generate.py --lang ru --takes 2        # весь сценарий, по 2 дубля
#    Лучший дубль переименовать в <id>.wav (дубли <id>__tN.wav дальше не идут)

# 2b. …или положить свои записи/TTS в audio/raw/ru/<id>.wav|mp3|ogg|flac

# 3. Нормализация -> audio/final/ru/
python3 tools/postprocess.py --lang ru          # или с --radio

# 4. Проверка и таблица для SoundModCreator
python3 tools/build_mapping.py --lang ru
#    -> build/smc_mapping_ru.md / .csv, build/Duke_Fleet/*.wav
```

## Сборка в SoundModCreator и установка

1. В SoundModCreator создайте мод с именем `Duke_Fleet`.
2. Для каждого раздела `build/smc_mapping_ru.md` выберите соответствующее игровое событие и добавьте все WAV группы. Когда файлов несколько, игра выбирает случайный.
3. Экспортируйте мод. Результат (`mod.xml` и аудио) должен оказаться в папке

   ```
   Мир кораблей\bin\<текущий билд>\res_mods\banks\mods\Duke_Fleet\
   ```

   Если ваша версия SoundModCreator умеет упаковывать в `.mkmod`, это альтернатива ручному копированию.
4. В игре откройте «Настройки → Звук → Модификация озвучки → Duke Fleet».

После обновления клиента номер билда в `bin\` меняется, и папку мода нужно перенести в новый билд.
